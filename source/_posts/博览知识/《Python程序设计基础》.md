Python规范：
（1）严格缩进，用于体现代码逻辑从属关系。一般4个空格作为缩进单位。
（2）每个import语句只导入一个模块。最好按标准库、扩展库、自定义库的顺序依次导入。
（3）提升代码可读性：

十进制里 1/3 是无限小数 → 我们只能近似存； 二进制里 0.1 也是无限小数 → 计算机也只能近似存

# 3.1 列表（list）
列表是**包含若干元素的有序连续内存空间**。
正向下标0开始，反向-1开始

# 3.2 元组（tuple）
元组是**有序、不可变**的序列，俗称“不能修改的列表”。

## 3.2.1 决定元组的是逗号，不是括号（重点易错）
括号在 Python 里是**表达式分组符**，只有当逗号出现时，括号才变成“元组构造符”。

```python
t1 = (1) # 括号仅分组 → 就是 1，type 为 int
t2 = (1,) # 逗号在 → 单元素元组，type 为 tuple
t3 = 1, # 省略括号，仍是元组
t4 = (1, 2) # 多元素，逗号天然存在，无歧义
t5 = () # 空元组是特例，无需逗号也不会有歧义
```

实测输出对比：
```text
my_tuple1 = (1) → 1 <class 'int'>
my_tuple2 = ("hello") → hello <class 'str'>

my_tuple1 = (1,) → (1,) <class 'tuple'>
my_tuple2 = ("hello",) → ('hello',) <class 'tuple'>
```

**单元素元组必须写成 `(元素,)`，尾逗号不能省略**：只有一个元素时，语法上没有任何标记能告诉解释器“要造元组”，唯一可用的符号只有逗号。

不写逗号的后果：
```python
(1,)[0] # 1，正常取元素
(1)[0] # TypeError: 'int' object is not subscriptable，代码直接崩
```

## 3.2.2 基本特征
| 特征 | 说明 |
|---|---|
| 有序 | 元素有固定位置，支持下标与切片 |
| 不可变 | 创建后不能增删改，`t[0] = 9` 报 TypeError |
| 可重复 | `(1, 1, 2)` 合法 |
| 类型混合 | `(1, "abc", 3.14, [1, 2])` 合法 |

## 3.2.3 常用操作
```python
t = (10, 20, 30)

t[0] # 10 按索引取
t[-1] # 30 反向索引
t[0:2] # (10, 20) 切片，结果仍是元组
len(t) # 3 长度
20 in t # True 成员判断
t + (40,) # 拼接成新元组
t * 2 # 元素重复
```

**“不可变”指元组里元素的引用不能被替换**。若元素本身是可变对象，其内部仍可修改：
```python
t = (1, [2, 3])
t[1].append(4) # 合法 → t 变为 (1, [2, 3, 4])
t[1] = [9] # 报错，元素引用不可替换
```

## 3.2.4 与列表的选择
| | 列表 `[]` | 元组 `()` |
|---|---|---|
| 可变性 | 可增删改 | 不可变 |
| 性能 | 稍慢 | 更快、内存占用更小 |
| 用途 | 动态数据集 | 固定结构、常量记录 |
| 可作字典键 | 不能 | 能（元素均可哈希时） |

判断原则：**数据要变用列表，一组固定值用元组。**

## 3.2.5 常见用途
```python
# 1. 函数返回多个值（本质是返回元组）+ 拆包
def min_max(nums):
 return min(nums), max(nums)
lo, hi = min_max([3, 1, 4])

# 2. 多变量赋值与交换
a, b = 1, 2
a, b = b, a

# 3. 作为字典的键
cache = {(0, 0): "origin"}

# 4. 保护常量数据不被误改
COLORS = ("red", "green", "blue")
```

## 3.2.6 实例：元组内嵌列表的可变边界
```python
my_tuple = (1, 2, 3, "hello", [1, 2, 3])
my_tuple[4][0] = 100
my_tuple[4][1] = 200
my_tuple[4][2] = 300
print(my_tuple)
```

输出：
```text
(1, 2, 3, 'hello', [100, 200, 300])
```

三行赋值改的都是**列表内部元素**，从未触碰元组第 4 号位置的引用，所以完全合法。

对照三种写法：
```python
my_tuple[4][0] = 100   # 允许：改列表内部
my_tuple[4] = [9]      # TypeError: 'tuple' object does not support item assignment
my_tuple[0] = 9        # TypeError：同上，元组元素不能重新赋值
```

**结论**：元组的“不可变”锁的是每一层元素的**引用**。元素本身若是可变对象（`list` / `set` / `dict`），其内部照旧可改。要彻底冻结，元素也必须是不可变类型（数字、字符串、元组、`frozenset`）。

记忆口诀：**元组 = 有顺序 + 不可改 + 逗号决定**；单元素那个逗号不是多余装饰，而是告诉解释器“我要元组”。
