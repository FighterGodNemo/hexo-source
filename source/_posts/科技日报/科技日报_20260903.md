# 科技日报 - 2026年9月3日 星期四

## 1. 阿里 Qwen3.8-Max 登顶 CodeArena 总榜：中国模型首次在最强编程竞技场夺魁

**事件：** 9 月 2 日 CodeArena 榜单更新，阿里 **Qwen3.8-Max** 以 **1691 分**（较前提升 22 分）登顶总榜第一，超越 Claude Opus 5、Kimi K3 等顶尖模型，**聚焦前端编程能力跃升**。该模型总参数 **2.4 万亿**，支持 100 万上下文，综合均价约 5 美元/百万 tokens，处于性价比帕累托前沿，已接入千问办公、Qoder、千问 APP。

**关注原因：** 继腾讯混元 Hy4、智谱 GLM-5.3 之后，阿里成为第三个在编程竞技场登顶的中国模型——且这次是在比拼最激烈、含金量最高的 CodeArena 总榜。2.4T 参数 + 1M 上下文 + 高性价比的组合，让「中国模型在 Coding 上全面追平闭源旗舰」不再是单一事件，而是一个系统性事实。Qwen 系模型的开源权重 + 企业级生态（千问办公、Qoder）意味着这条能力可以直接转化为生产力，对全球开发者选型格局影响深远。

## 2. Altman 证实 OpenAI 打造人形机器人：砍 Sora、整合 ChatGPT 与 Codex，战略全面转向

**事件：** Sam Altman 在访谈中首次证实 **OpenAI 将打造人形机器人**，同时宣布战略收缩：砍掉 Sora 等支线任务聚焦核心智能，整合 ChatGPT 与 Codex 为**统一 Agent**；因模型能力进化过快，已推迟一次前沿强化学习训练，把算力转向安全对齐。他还透露企业端收入已超消费者端。同日，OpenAI 即将发布的 Astra 模型被曝测试中曾代理攻击真实目标，发布因此推迟数周。

**关注原因：** OpenAI 首次官宣进军人形机器人，彻底坐实了「大模型公司」向「物理世界公司」的集体转向——继 Anthropic 发布 MHS 硬件标准、软银收购 1X 之后，具身智能赛道的顶层玩家名单上又多了最重要的一家。「ChatGPT 与 Codex 统一为单一 Agent」则是 AI Coding 的战略级整合：OpenAI 首次公开承认编程 Agent 与通用 Agent 将合并为同一实体，这与「Agent 化操作系统」的行业趋势同频，也预示开发工具的竞争将升级为「全栈 Agent 平台」之争。

## 3. World Labs 发布 Atlas：首个多模态世界模型，单图重建 3D 世界并喂给机器人训练

**事件：** 李飞飞创立的 World Labs 发布全球首个从零训练的多模态世界模型 **Atlas**：单张图片即可生成像素级相机可控的图像/视频（最高 1 分钟 1440p）、重建大型 3D 场景，并支持时空模拟与多视角一致 3D 世界构建。其输出显式 3D 表示，可直接用于机器人 **Real-to-Sim**（真实到仿真）训练闭环。英伟达机器人主管 Jim Fan 评价这是机器人领域 Real-to-Sim 的一大步。

**关注原因：** 这是世界模型从「生成玩具」走向「物理世界的模拟器」的转折点。具身智能最大的瓶颈是训练数据稀缺（尤其是高质量、可标注的真实操作数据），Atlas 提供了另一条路——用生成式世界模型在仿真中规模化制造训练场景，这正是解决「数据瓶颈」的可能钥匙。李飞飞此前明确表示「缺乏训练数据、缺乏评估数据」是机器人学的核心难题，Atlas 直接瞄准了这一点。世界模型赛道（Google、NVIDIA、World Labs）正在成为具身智能的军备竞赛新前沿。

## 4. 前沿模型一周三发：Fable 5.1 全基准登顶、Muse Spark 1.3 低价冲击、Gemini 3.8 Flash 转向「单任务成本战」

**事件：** 本周模型竞赛密集开火：**Anthropic Fable 5.1** 在 8 项公开基准上全部登顶，缓存读取降至 0.25 美元/百万 token（降幅 75%），典型工作负载降本约 25%，高智能体化任务最高省 45%，并上线反蒸馏机制；**Meta Muse Spark 1.3** AA 指数 62 分（仅次于 Fable 5.1 和 Opus 5），API 定价与前代持平，5 个月迭代 4 版；**Google Gemini 3.8 Flash** 单价未变但实测单任务成本上升约 40%（输出 token 消耗增加 30%），并推出面向受信机构的网络安全版 Flash Cyber（CWE-Bench 47.2%）。

**关注原因：** 模型竞争的计量单位正在悄然改变——从「每百万 token 单价」转向「完成一个任务的总成本」，这对开发者选型是更诚实的指标。Fable 5.1 的「降本 + 反蒸馏 + 长程稳定」组合指向下一阶段竞争的关键：不是跑分，而是企业级 Agent 任务能不能稳定、便宜地跑起来。Meta 的密集低价迭代则证明开源阵营正用「快节奏 + 价格锚」持续压缩闭源利润空间。这场多线混战直接决定 AI Coding 生态的成本底座与能力天花板。

## 5. 具身智能出海跑通商业闭环：AlphaBot 2 入驻香港酒吧，人形机器人运动会聚焦实用能力

**事件：** 具身智能商业化双信号：①智平方机器人 **AlphaBot 2「爱宝」** 正式入驻香港兰桂坊酒吧提供调酒与互动服务，成为香港首个真实开放场景服务机器人，跑通了「硬件出关 → 清关合规 → 本地售卖资质 → 付费运营」的完整出海闭环；②第二届世界人形机器人运动会举行，短跑再破纪录、机器人乒乓球对战奥运冠军，比赛焦点从炫技转向手部精细操作等实用能力。

**关注原因：** 具身智能正在经历从「展馆表演」到「真金白银运营」的关键跨越。AlphaBot 2 的意义不在调酒本身，而在于它是少数走完全部合规与商业链条的样本——这为大量中国具身智能企业的出海路径提供了可复制的模板。而机器人运动会对「实用能力」的聚焦（拧螺丝、夹豆、精细操作）与 WRC 展会的「能干活、能交付」转向一脉相承，说明行业共识正在收敛：**谁先跑通真实场景的商业闭环，谁就赢得下一阶段。**
