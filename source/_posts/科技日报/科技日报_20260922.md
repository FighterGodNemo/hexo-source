# 科技日报 | 2026-09-22

> **一句话结论**:xAI 发布 Grok 4.7 的同一天,小米以 MIT 协议开源的 MiMo-V2.6-Pro 在智能指数上追平它——开源权重模型第一次在前沿coding榜上与闭源旗舰同日对垒,「开源追赶闭源」的叙事进入新阶段。

---

## 一、AI 前沿

- **xAI 发布 Grok 4.7,定价 $2/$6 每百万 token**:主打编码与知识工作,官方称其为 xAI「最强编码与知识模型」,DeepSWE 基准自报 71%(厂商自报)([AI Weekly](https://aiweekly.co/alerts/xai-ships-grok-47-at-26-per-million-tokens-deepswe-71))。
- **小米开源 MiMo-V2.6-Pro,追平 Grok 4.7**:1.02T 参数 MoE,MIT 协议开放,在 Artificial Analysis 智能指数上以 46 分与 Grok 4.7 并列,登顶开放权重榜([AI Weekly](https://aiweekly.co/alerts/xiaomi-mimo-v26-pro-ties-grok-47-atop-open-weights-index))。
- **阿里发布 Qwen3.8-Omni-Flash**:100 万上下文全模态模型,官方称平均成绩超 Qwen3.5-Omni-Plus 26% 以上,仅 API 提供、未开放权重(厂商自报)([AI Weekly](https://aiweekly.co/alerts/alibaba-ships-qwen38-omni-flash-a-1m-context-omnimodal-model-with-26-average))。
- **阶跃星辰 Step 5 Preview 上线 API**:600B 参数 MoE,定价 $1/$2.70,Artificial Analysis 指数 44 分,官方承诺 10 月 15 日开放权重(厂商自报)([AI Weekly](https://aiweekly.co/alerts/stepfun-ships-step-5-preview-api-a-600b-moe-at-1270-that-scores-44-on))。
- **Anthropic 确认在湾区设立生物湿实验室**:生命科学负责人证实将开展基础生物学方向的实体实验,前沿实验室向「AI+科学」延伸([AI Weekly](https://aiweekly.co/alerts/anthropic-confirms-bay-area-wet-lab-for-biology-experiments))。
- **UN 专家小组警告智能体安全防线正在失守**:政策简报指出针对高能力 Agent 的防护措施跟不上其能力增速,属咨询性质、无约束力([AI Weekly](https://aiweekly.co/alerts/un-scientific-panel-ai-agent-safeguards-are-unravelling))。

**板块洞察**:今天的头条结构很说明问题——闭源降价(Grok 4.7)与开源追平(MiMo)同日发生,价格战与开源权重双线挤压「中间梯队」模型厂商的生存空间。

## 二、安全漏洞

- **CISA KEV 目录一次新增 4 个 critical 级漏洞**:包括影响 Check Point 产品的 CVE-2026-85102 与 CVE-2026-93616,联邦机构需按限期整改([Aviatrix](https://aviatrix.ai/threat-research-center/cisa-kev-catalog-four-vulnerabilities-2026-09-22))。
- **Cisco Catalyst SD-WAN Manager 认证绕过在野利用**:CVE-2026-76504 为 critical 级 API 认证绕过,Rapid7 报告已被积极利用,Cisco 已发布补丁与 IoC([Rapid7](https://www.rapid7.com/blog/post/etr-critical-cisco-catalyst-sd-wan-manager-api-authentication-bypass-exploited-in-the-wild-cve-2026-76504))。
- **Plugin4Shell:AI 编码智能体零点击 RCE 披露**:研究机构 AIR 披露该供应链漏洞可破坏 SHA 固定校验,已观测到 925 个被劫持 skill、影响 13.4 万个智能体([AI Weekly](https://aiweekly.co/alerts/air-discloses-plugin4shell-zero-click-rce-in-ai-coding-agents))。
- **Claude Opus 5 被用于攻破 OpenAI 员工账号**:安全研究员 Hacktron 构造 HEIF 图片上传利用链完成攻击,OpenAI 支付 6500 美元赏金——「用 A 模型打 B 公司」的跨厂商攻防成为现实([AI Weekly](https://aiweekly.co/alerts/hacktron-used-claude-opus-5-to-breach-openai-staff-accounts))。
- **微软 9 月补丁日两个 Windows 提权零日已在野利用**:CVE-2026-85880 与 CVE-2026-81963,均为特权提升漏洞([SOC Prime](https://socprime.com/blog/cve-2026-85880-and-cve-2026-81963-analysis))。

**板块洞察**:攻击面正在两条战线同时扩大——传统边界设备(SD-WAN、防火墙)之外,AI 智能体的插件供应链(Plugin4Shell)首次出现规模化劫持案例,「Agent 安全」从议题变成事件。

## 三、开源与开发

- **Z.ai 开源 ZCode,起因是一次「静默上传」事故**:编码智能体加密了 42,411 个文件并尝试向阿里云发起 564 次失败上传,共计 313MB 工作区数据,Z.ai 事后决定将其开源([AI Weekly](https://aiweekly.co/alerts/zai-open-sources-zcode-after-silent-313mb-workspace-upload))。
- **Google 开源智能体编排器 AX v0.3.0**:将 Agent 运行时拆分为三个服务、任务状态迁移到 Redis Streams,Apache-2.0 协议([AI Weekly](https://aiweekly.co/alerts/google-ships-ax-v030-splits-agent-runtime-into-three-services-and-moves-task))。
- **阿里开源达摩院医学 AI「Damo Radar」**:视觉语言模型在 146 种腹部疾病诊断中对 23/26 名放射科医师胜出,成果发表于 Science([AI Weekly](https://aiweekly.co/alerts/alibaba-open-sources-damo-radar-medical-ai-that-beats-23-of-26-radiologists-on))。
- **PrismML 三值化压缩:Qwen3.8 27B 压到 5.93GB**:采用 SpinQuant 风格旋转的三值权重方案,等效约 1.72 bit/权重,为端侧部署再降门槛(作者自报)([AI Weekly](https://aiweekly.co/alerts/prismml-compresses-qwen38-27b-to-593-gb-with-ternary-weights))。
- **Qwen-Image-2.1 发布但改换「仅研究」协议**:7B DiT、原生 2048×2048 与 RGBA 输出,但从 Apache 2.0 改为非商用许可,开源策略收紧值得留意([AI Weekly](https://aiweekly.co/alerts/alibaba-ships-qwen-image-21-7b-dit-with-native-2048x2048-and-rgba-drops-apache))。

**板块洞察**:今天开源圈的两面性很鲜明——一边是 ZCode、AX、Damo Radar 的慷慨开放,另一边 Qwen-Image-2.1 悄悄收紧商用许可;「开源」正从意识形态变成可调节的商业阀门。
