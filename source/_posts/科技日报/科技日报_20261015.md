## 三、开源与开发

- **Ubuntu 26.10 正式发布，代号 “Stonking Stingray”**：作为 26.04 LTS 之后的过渡版本获 9 个月支持（至 2027 年 7 月），搭载 GNOME 51 与 Linux 7.3（首发镜像因上游最终版未就绪基于 7.3-rc6 构建），图形栈更新至 Mesa 26.2。来源：[IT之家](https://www.ithome.com/1/013/633.htm)
- **Ubuntu 26.10 完成 Rust 核心工具的全面迁移**：默认命令行工具已 100% 运行在基于 Rust 的 uutils 实现之上，此前为兼容性保留的最后三个 GNU 命令 `cp`、`mv`、`rm` 在本次发布中完成切换，Canonical 自 25.10 启动的过渡正式收官。来源：[IT之家](https://www.ithome.com/1/013/633.htm)
- **Ubuntu 26.10 的硬件与架构扩展**：新增对高通 Snapdragon X Elite / X2 Elite 笔记本的初步支持及部分 X Elite 机型内置摄像头驱动；**首次提供 RISC-V 桌面镜像**，支持 SpacemiT K3 与 SiFive BigSky 平台；App Center 新增独立驱动管理页可选择 NVIDIA 驱动分支。来源：[IT之家](https://www.ithome.com/1/013/633.htm)
- **Anthropic 宣布弃用 Git，转用自研版本控制系统 Scion**：官方称 5 月平均每天合并 2500 次代码变更，9 月已超过 3 万次，Git 无法满足需求；Scion 的 CPU 和内存消耗据称仅为 Git 的**二百分之一**，切换后 CI 与研究任务的代码检出仅需几秒而非数分钟。Scion 将提交、合并、变基和文件历史查询放在服务器端执行，客户端只跟踪本地修改、维护有限缓存。来源：[IT之家](https://www.ithome.com/1/013/670.htm)
- **Anthropic 的 Scion 难以被直接复制**：因需要配套定制代码审查、搜索与 CI 工具链（此为媒体分析视角）。来源：[IT之家](https://www.ithome.com/1/013/670.htm)
- **阶跃 Step 5 Preview 部署路径明确**：权重在 Hugging Face / ModelScope，可用 vLLM 或 SGLang 部署兼容 OpenAI 接口的 API 服务，也可用 Transformers 离线推理。来源：[IT之家](https://www.ithome.com/1/013/663.htm)
- **国产开源模型工程化进展两项**：游戏世界模型压进单张 RTX 5090 并开源；另一款多模态模型可在 iPhone 断网运行 35B、内存占用约 3G。来源：[量子位](https://www.qbitai.com/2026/10/503353.html)、[量子位](https://www.qbitai.com/2026/10/503109.html)
- **百度世界 2026 定档 11 月 12 日**，官方称将有重磅嘉宾与企业级 AI 产品集中亮相。来源：[IT之家](https://www.ithome.com/1/011/859.htm)
- **量子位智库发布 Agent 落地报告**，拆解企业智能化六大断点并给出全链路破局框架。来源：[量子位](https://www.qbitai.com/2026/10/503614.html)

**板块洞察**：Linux 基础栈正在完成一次静默但关键的地基替换——Ubuntu 把 cp/mv/rm 全部切到 Rust、移除 WEP、引入 OpenSSL 4 与后量子推进，这些都是安全债的偿还而非功能更新；而 Anthropic 的 Scion 则从另一侧印证了同一件事：当 Agent 每天提交三万次变更时，传统客户端-服务器版本控制模型本身已经成了瓶颈。
