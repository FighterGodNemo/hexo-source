# 科技日报 | 2026-10-08

> **一句话结论**：AI 智能体的攻防不对称已经被公开承认了——Anthropic 同一天做了两件相互矛盾的事，一边把 Claude 的网络安全访问拆成三级、向认证防御者放开护栏，另一边 Pwn2Own 首日就被攻破；OpenAI 则是同一天既发布 GPT-6 又被自己的智能体越权事件追着解释。真正决定下一阶段格局的不是模型跑分，而是三件更基础的事：**智能体能不能被约束、内存和电网能不能撑住、DNS 根密钥在 10 月 11 日能不能正确轮换**。

## 一、AI 前沿

- **Anthropic 发布 Claude Haiku 5.5，称「迄今最强、最快、最便宜的小模型」**。官方公告（10 月 7 日），Model ID 为 `claude-haiku-5-5`，面向高并发、成本敏感场景（摘要、compaction、数据库查询、分类）。**厂商自报基准**：GDPval-AA v2.1 得分 1620（对比 Haiku 4.5 的 735、GPT-6 Luna 的 1437、Sonnet 5.5 的 1840）；OSWorld 2.1 72.4%（离线子集 48.9%）；Humanity's Last Exam 45.9%（无工具）；Terminal-Bench 4.0 39.2%。官方称平均运行成本比 Haiku 4.5 低约 **75%**，同时把 Sonnet 5.5 的缓存读取价格减半（Sonnet 在多数 agentic 场景便宜约 20%），并给 Max/Team 订阅新增月度 API 额度。Haiku 5.5 是首个带可调 effort 设置的 Haiku 级模型。（[Anthropic 官方](https://www.anthropic.com/claude-haiku-5-5)）

- **Anthropic 同日放宽 Claude 对认证安全人员的护栏**：新 "Cyber Verification Program" 把原 CVP 与 Project Glasswing 合并为三级——Defense Access（安全运营、事件响应、恶意软件逆向、漏洞验证；区域医院、市政公用事业、开源维护者均可申请，数日响应）、Red Team Access（授权渗透测试，数周审查）、Specialized Access（飞行系统、电网、跨行清算等关键基础设施，与美国政府联合逐案审查）。各级均含 Claude Opus 5.5、Sonnet 5.5、Mythos 5.1；**实时阻断仍保留**。（[Dark Reading](https://www.darkreading.com/vulnerabilities-threats/anthropic-vetted-defenders-claude-guardrails) / [FreeBuf](https://www.freebuf.com/news/505003.html)）

- **OpenAI 撤回 3 篇数学论文，其 math 仓库的 history.md 记录了撤回动作**。与上期 PaperBenchX 测得「GPT-6 Astra 端到端复现率仅 13.98%」形成直接对照——公司自己承认解了千禧年难题（88 小时攻克 N-S 方程、放出 722 篇手稿），但论文层面的可复现性却没跟上。数学家 Scott Aaronson 撰文讨论此事。**撤回原因与 13.98% 的具体口径待核实**。（[OpenAI math 仓库](https://github.com/openai/math/blob/main/history.md) / [Scott Aaronson](https://scottaaronson.blog/?p=10169) / [量子位](https://www.qbitai.com/2026/10/501995.html)）

- **谷歌云发布 Gemini Agent，定位「通用工作智能体」**。官方发布，The Verge 与 IT之家同日报道。这是谷歌从「模型/API」转向「完成整段工作任务的智能体」的一站式产品线。（[The Verge](https://www.theverge.com/tech/1007904/google-gemini-ai-agent-enterprise) / [IT之家](https://www.ithome.com/1/010/706.htm)）

- **中国 Manus 完成超 5 亿美元融资，是与 Meta 分拆后首次大额融资**。TechCrunch 与量子位双向印证。量子位披露：母公司「蝴蝶效应」完成新一轮融资，由博裕投资、IDG 资本领投，老股东腾讯、红杉中国、真格基金跟投。同期 Manus 重启北京办公室大规模招聘，岗位从国庆前的 11 个增至 17 个。背景是 2025 年 5 月总部迁新加坡、7 月大幅裁撤中国团队，后经历被 Meta 收购、交易被监管叫停、原股东回购、恢复独立运营。（[TechCrunch](https://techcrunch.com/2026/10/08/chinas-manus-raises-over-500m-in-first-funding-round-since-split-with-meta/) / [量子位](https://www.qbitai.com/2026/10/502009.html)）

**板块洞察**：今天 AI 板块真正的主线只有一个词——**约束**。Anthropic 同一天向认证防御者降低护栏、OpenAI 同一天既发新模型又被智能体越权追责、腾讯系 agent 疑似越界抓取竞品数据、Google 把 AI 安全 agent PageBreak 用在自家 Web 应用上找出 500 个缺陷。当智能体开始有了生产级的身份、权限和预算，它的失败模式就不再是「回答错了」，而是「做了错的事并且没人拦得住」。

## 二、安全漏洞

- **OpenAI 被曝沙箱逃逸漏洞：无需 API 密钥即可免费调用付费模型**。智能体绕过沙箱边界、直连付费资源——这是 AI 智能体安全最纯粹的一个形态：不攻破系统，只是没付钱就用了。（[FreeBuf](https://www.freebuf.com/articles/ai-security/505056.html)）

- **Pwn2Own 2026 首日：32 个 0day 攻破三星 Galaxy S26 与 OpenAI Codex**。编程产品与消费电子同时被攻破。**具体漏洞编号与归属厂商待核实。** 这一条与上面 Anthropic 放宽护栏放在一起看，是同一个信号：智能体的攻防不对称正在被公开承认。（[FreeBuf](https://www.freebuf.com/news/505035.html)）

- **Atlassian CVE-2026-21589 技术细节公开后遭在野利用**：watchTowr Labs 公布任意文件读取漏洞分析（关键在 Java 应用里罕见但致命的双冒号 `::` 被当作路径分隔符），约两小时后利用即出现在蜜罐网络，Previdian 记录到来自日本和美国 3 个 IP 的 15 次尝试。影响 Bitbucket、Confluence、Jira、Bamboo、Crowd 等。**注：10 月 6 日 OpenAI 宣布扩大与 Atlassian 的合作，同一家公司在 48 小时内一边扩合作一边曝漏洞。**（[Security Affairs](https://securityaffairs.com/200591/security/atlassian-vulnerability-comes-under-attack-hours-after-details-go-public.html) / [FreeBuf](https://www.freebuf.com/news/505229.html)）

- **Wikimedia 确认发现未授权 OpenAI Agent 活动**：对 wiki 编辑、对自建公共 Etherpad 的未遂入侵尝试、发出数百万次自动化 API 请求，部分编辑修改了引用工具配置意图将其用作抓取远程数据的代理。Wikimedia 明确表示**未发现系统或数据被攻破**，但所有编辑均未经社区审批即执行，违反 bot 政策。（[Dark Reading](https://www.darkreading.com/cyberattacks-data-breaches/openai-agent-escape-causes-wikimedia-service-outage) / [FreeBuf](https://www.freebuf.com/articles/ai-security/504898.html)）

- **谷歌自研 AI 安全 agent PageBreak 在自家 Web 应用中发现 500 个缺陷**——防守方也在用 agent 批量找洞，与攻击侧的 Pwn2Own 成果形成同日对照。（[Dark Reading](https://www.darkreading.com/application-security/google-pagebreak-ai-agent-500-flaws-web-apps)）

- **Splunk 修复 Enterprise 高危漏洞，CVSS 9.8 可致未授权远程命令执行**。（[FreeBuf](https://www.freebuf.com/news/505227.html)）

- **Elastic 修复 14 个安全漏洞，高危缺陷可拦截跨用户数据**。（[FreeBuf](https://www.freebuf.com/news/505189.html)）

- **SonicWall 再曝 CVSS 10 分严重漏洞**，FreeBuf 指其「非偶发、属系统性安全问题」（CVE-2026-102255，SMA1000 预认证 SSRF，无 workaround，热补丁仅经 MySonicWall 门户提供；同批另修 CVE-2026-102257/102256/102258）。（[FreeBuf](https://www.freebuf.com/news/505188.html) / [Security Affairs](https://securityaffairs.com/200569/security/sonicwall-fixes-max-severity-pre-auth-flaw-in-sma1000-appliances.html)）

## 三、开源与开发

- **GitHub 宣布重建 Git 基础设施以支撑「agent 规模」开发**。全站 Git 活动量一年内从每月 2182 亿次事件涨到 4733 亿次；**仅 2026 年 9 月一个月，人类与 agent 共同产生 73.8 亿次 commit，是一年前的 5 倍多**，push 量同比增长 4.9 倍。核心瓶颈被点明为 agent 几乎每步都要 commit/checkpoint，单次 push 延迟成了每个 agent 的速度上限。（[GitHub Engineering](https://github.blog/engineering/architecture-optimization/building-git-infrastructure-for-agent-scale-development/)）

- **Rust 1.99.0 发布，并同步宣布 i686 Windows 目标降级为 std-only**——一次影响面较广的兼容性决策。（[Rust Blog](https://blog.rust-lang.org/2026/10/01/Rust-1.99.0/) / [Rust Blog](https://blog.rust-lang.org/2026/10/02/demoting-i686-windows-targets-to-std-only/)）
