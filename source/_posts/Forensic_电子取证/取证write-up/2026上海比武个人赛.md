## 二、流量分析

### 1. 通过对流量分析，在员工登录系统的流量中，发现管理员密码被意外泄露，请找出真实的管理员密码。

> 简答 ｜ 答案格式：按实际值填写

正确答案：company_2024_admin

依据：`K:\流量\流量检材.pcap`（Raw IPv4，4110 帧）。员工登录 POST（帧 3133–3141 `oa.company.com /login`、帧 3450–3458 `mail.company.com /webmail/login`）里的 `password0`–`password4` 都是占位干扰值，登录流响应为 `HTTP/1.1 401 Unauthorized / Login Failed`。全文件按 `frame contains "admin"` 检索只命中帧 3143–3147（管理面板）与 3456，这 5 条管理请求的 `debug` 参数是 5 个候选口令，其中只有帧 3145 的 Cookie 是 `admin=true`（其余 4 帧均 `admin=false`），并且该帧带 `Authorization: Bearer` JWT，即唯一的管理员特权会话：

```powershell
tshark -n -r 'K:\流量\流量检材.pcap' -Y 'frame contains "admin"' -T fields -e frame.number -e http.request.uri
# 3143  /admin/settings?user=admin&debug=system%5Finfo%5Fdebug&mode=dev
# 3144  /admin/panel?user=testuser&debug=test%5Fpassword%5F123&module=config
# 3145  /admin/panel?user=admin&debug=company%5F2024%5Fadmin&module=users
# 3146  /admin/logs?user=admin&debug=backup%5Fconfig%5F2024&type=security
# 3147  /admin/panel?user=admin&debug=admin%5Fkey%5F2024&module=auth

tshark -n -r 'K:\流量\流量检材.pcap' -Y 'frame.number==3145' -x
# ...Cookie: JSESSIONID=B4A5C9E8D7F6E3A2B1C1; admin=true..Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9
```

限制：这 5 条管理面板请求在抓包中没有对应的服务器响应帧，判定依据是同一请求中的 `admin=true` 会话标识。

### 2. 通过对流量分析，发现异常的 DNS 查询活动，可能存在 DNS 隧道，请对异常的 DNS 查询进行解码，还原其隐藏的数据内容。

> 简答 ｜ 答案格式：按实际值填写

正确答案：pythomdimentent forld!

依据：482 条 DNS 帧中按标签长度筛选（>24 字符）只有帧 3448 异常，是单条 Base32 编码的隧道标签，发往解析器 8.8.8.8（UDP 53，源 192.168.10.102），`count.answers=0`（无应答，仅查询侧可还原）；其余查询均为 `randomN.example.com`、`serviceN.company.com` 这类顺序编号，无编码结构。原始帧字节确认标签逐字符为 `OB4XI2DP NVSGS3LF NZ2GK3TU EBTG64TM MQQQ`（Base32 字母表 A–Z、2–7），36 字符解出 22 字节，反向 `base32encode` 回验得到同一标签，说明无缺块、无填充错误。

```powershell
tshark -n -r 'K:\流量\流量检材.pcap' -Y 'dns' -T fields -E separator='|' -e frame.number -e dns.flags.response -e dns.qry.name -e dns.qry.type
# 3448|False|OB4XI2DPNVSGS3LFNZ2GK3TUEBTG64TMMQQQ.files.company.com|1
```

```python
import base64
s = 'OB4XI2DPNVSGS3LFNZ2GK3TUEBTG64TMMQQQ'
d = base64.b32decode(s + '=' * ((8 - len(s) % 8) % 8))
print(d, base64.b32encode(d).decode().rstrip('='))
# b'pythomdimentent forld!'  ->  OB4XI2DPNVSGS3LFNZ2GK3TUEBTG64TMMQQQ
```

解码按字面值给出（形似 “python environment for ld!” 的残缺文本），不作修正。
