#### 25. 聊天数据库中，显示聊天数据删除的是哪个字段

从内部通联 APK 的 Flutter AOT 库中可直接提取到建表 SQL 与查询 SQL。`conversation_member` 表中存在删除标记字段：

```sql
CREATE TABLE IF NOT EXISTS conversation_member (
  id TEXT PRIMARY KEY,
  conversation_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  role TEXT DEFAULT 'member',
  join_at INTEGER NOT NULL,
  unread_count INTEGER DEFAULT 0,
  last_read_at INTEGER,
  last_read_message_id TEXT,
  is_muted INTEGER DEFAULT 0,
  is_pinned INTEGER DEFAULT 0,
  is_deleted INTEGER DEFAULT 0
)
```

应用读取会话列表时过滤删除记录：

```sql
SELECT c.*, cm.unread_count, cm.is_pinned
FROM conversation c
INNER JOIN conversation_member cm ON c.id = cm.conversation_id
WHERE cm.user_id = ? AND cm.is_deleted = 0
ORDER BY cm.is_pinned DESC, c.last_message_at DESC
```

同时 APK 中还存在索引：

```sql
CREATE INDEX IF NOT EXISTS idx_conv_member_deleted ON conversation_member(user_id, is_deleted)
```

因此显示聊天数据删除状态的字段为：

```text
is_deleted
```
